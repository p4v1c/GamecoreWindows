A console front-end for the PC under your TV.

GameCore signs your Windows PC in, covers the screen and gives you a console you drive with a gamepad: a library, five themes, profiles, suspend and resume, Rest mode. The PC stays a PC underneath.

Download Source on GitHub

Windows 10 and 11, 64-bit. Early releases: the emulator packs are not in yet.

Download

One archive holds GameCore and its installer. The installer is a PowerShell script: it shows what it would change first, asks for administrator rights once, and running it again is safe.

GameCore for Windows

Unpack it, then run the installer from the folder.

Download gamecore-ota.zip 
Expand-Archive gamecore-ota.zip setup
cd setup
Set-ExecutionPolicy -Scope Process Bypass
.\install\install.ps1 -DryRun
.\install\install.ps1

Check it against its SHA-256 before you run it.

What the PC needs
Windows 10 version 1809 or Windows 11, 64-bit, an administrator account, a 1080p screen and 4 GB of RAM. Python and Caddy come with the installer.
What it changes on the PC
Automatic sign-in, a logon task, the power button and sleep settings, a web service on port 8443 and its firewall rule. Every change is recorded, and the uninstaller puts them back.
Coming from the Linux box
A script copies your ROMs, saves, covers, profiles and playtime from its data partition into the Windows data folder. See the README.

Five looks, one console

Every theme runs the same screens with the same pad controls. Switch between them in Settings, and anyone can write a new one with the theme SDK.

A quiet dark console. The games carry the colour.

From the download to a working console

A few minutes, most of them spent downloading.

  1. Run the installer on the PC

    Read the dry run, then run it for real. It asks where your games go, a password for web access and your Windows password for automatic sign-in, through Windows' own prompts.

  2. Restart

    The PC signs in by itself and comes up on the console screen. Return to desktop in the Power menu gives you Windows back.

  3. Pick up a controller

    The first pad is Player 1 whatever its brand, the next is Player 2. A pad nothing recognises goes through a mapping wizard, one button at a time, no keyboard.

  4. Add your games, and let it update itself

    Copy them into the per-system folders, or drop them in the browser from your phone with the ROM Manager addon. Updates install from Settings, and a version that does not start is rolled back by itself.

What you get

  • A console, not a launcher

    Suspend a game with the Guide button and come back to it, see who is playing, close everything and rest the PC from the Power menu. Wi-Fi, Bluetooth, display and audio are in Settings, readable from the sofa.

  • Your library, dressed

    Covers, 3D boxes, screenshots and synopses, matched by the game file itself rather than its name, with an offline database when you have no scraper account.

  • Still a real computer

    Nothing is locked. Return to desktop, use the PC, click the GameCore shortcut to come back. The installer records every change it makes, and the uninstaller undoes exactly those.

What it does not do yet

Better read here than found out after an install.

  • No emulator packs yet. The Linux edition's packs install Flatpaks; each is being rewritten for Windows. Until then no console appears in the library.
  • No bezel overlay around games, and no graphical installer.
  • Tested on one PC. The installer and the updater have run in a test folder and as dry runs; a full install on a fresh PC is the next check.
  • Unsigned. Windows SmartScreen may warn about the shell on first start.
  • One developer. The bus factor is one.
  • No games, ROMs, BIOS files or keys are distributed, downloaded or included. Bring your own.
