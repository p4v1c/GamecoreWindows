# Windows port — Linux-only tests, by the step that removes them

Tests of Linux code the port has not replaced yet. Each is skipped on Windows
with its step named (`linux_until_port`, [`../TESTING.md`](../TESTING.md)) and is
**deleted with that code** in that step's PR, row included.
`backend/tests/test_linux_until_port.py` fails when this table and the source
disagree.

Measured on 19/10/2026 (step 2): 464 test items in 66 files, by step:

| Step | What replaces the Linux code | Items |
|---|---|---|
| 3 | process/session: Job Objects, `NtSuspendProcess`, WTS session, argument quoting | 91 |
| 4 | the overlay window and its backend leave the port | 2 |
| 5 | pads (SDL), battery, storage, Bluetooth | 30 |
| 6 | Rest mode: sleep, wake by pad | 21 |
| 7 | installer, logon task, CLIs; the Linux packs leave with the Linux providers | 282 |
| 8 | OTA updater and release workflow | 26 |
| 9 | addon CLI (`gamecore-addons-windows`) | 9 |
| 10 | Linux data migration scripts, replaced by `scripts/import-linux-data.py` | 3 |

"all (N)" marks a whole file (`pytestmark`, or `linux_until_port_module` for
the files Windows cannot import); otherwise the marked tests are named and the
rest of the file runs on Windows.
